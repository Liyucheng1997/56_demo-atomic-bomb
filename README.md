# 原子弹是如何工作的 · 交互式科学可视化 (Three.js)

> 当前版本：**v1.2**

从一个原子核讲到蘑菇云，用 5 个章节讲清原子弹的基本原理。每章都有可拖动的时间轴、分步讲解和实时物理读数。纯前端单文件，浏览器直接打开 `index.html` 即可（Three.js 通过 CDN 加载，需联网）。

核心逻辑：**中子 → 裂变 → 放出更多中子 → 材料超临界 → 链式反应指数增长 → 微秒内释放巨大能量**

## 章节

| 章 | 内容 | 看点 |
|---|---|---|
| 1 裂变 | 一个中子劈开铀-235 核 | 236 个核子逐个建模；复合核振荡 → 液滴拉长 → 断裂成钡-141 + 氪-92 + 3 个中子 + γ 射线；质量亏损 E = mc² 逐项计算 |
| 2 链式反应与临界 | 中子的三种命运 | **实时蒙特卡洛模拟**：可调质量、压缩密度、反射层，实时估算 k 值，并用对数曲线显示中子数；6 个预设依次演示次临界、临界质量、压缩、反射层和指数增长 |
| 3 枪式原子弹 | 把两块次临界铀“拼”在一起 | 实体剖切模型（剖面带剖面线），弹丸沿炮管加速、合体后 k 跃升、约 80 代链式反应、火球；说明效率低、钚不适用的原因 |
| 4 内爆式原子弹 | 把一块钚“压”到超临界 | 同心球层剖切；雷管同步起爆，波阵面发光带向心汇聚，炸药燃尽变暗，核心压缩后密度约翻倍；**可切换“不同步起爆”对比哑火** |
| 5 爆炸与效应 | 火球、冲击波与蘑菇云 | 按泰勒强爆炸解 R ≈ (Et²/ρ)^1/5 计算火球和冲击波；入射波、地面反射波与马赫波；尘土裙、云柱、翻滚的环形涡旋菌盖；时间轴按对数压缩（µs → min）；效应范围俯视图（当量 1 kt – 1 Mt） |

## 界面

- **左侧**：章节导航、本章控制（视图切换、部件列表、模拟参数等）
- **右侧**：分步讲解，包含公式和关键数据
- **顶部**：物理读数，如增殖因子 k、核心密度、链式反应代数、累计能量、能量去向
- **底部**：时间轴（播放/暂停、拖动、步骤节点、倍速），并显示对应的真实时间尺度
- 3D 标注带引线，点击模型部件可单独查看

操作：拖动旋转 · 滚轮缩放 · 右键平移 · 空格播放/暂停 · ← → 切换步骤

## 使用

直接双击 `index.html`，或本地起静态服务器：

```bash
python -m http.server 8000
```

然后在浏览器打开 http://localhost:8000 。

## 说明

仅用于科普、课堂和博物馆式展示。装置内部为概念示意（非工程比例，不含制造信息）；第 2 章为玩具模型，数值只用于说明规律；效应范围为按经验比例律估算的数量级，受爆高、天气、地形影响很大，不能用于现实预测或安全决策。
