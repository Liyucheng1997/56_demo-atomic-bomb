# 原子弹结构与威力可视化 (Three.js)

交互式三维核裂变武器可视化。纯前端单文件，浏览器直接打开 `index.html` 即可（Three.js 通过 CDN 加载，需联网）。

## 功能

- **两种弹型，一键切换**
  - 内爆式钚弹（Fat Man / 胖子）：同心球壳结构，32 块炸药透镜向心内爆压缩钚核。
  - 枪式铀弹（Little Boy / 小男孩）：炮管把 U-235 弹丸射入靶环，两块铀合体超临界。
- **详细结构** — 外壳、炸药透镜 / 枪管、推进 / 夯实层、铀反射层、核心、中子源；每层可点击隔离观察，附中英文名称、原理与参数。
- **三种视图** — 整体 / 剖面（实时裁剪平面）/ 分解。
- **引爆序列动画** — 按真实物理链逐阶段演示，微秒级计时，可调速。
- **蘑菇云** — 2200 粒子的云柱 + 翻滚菌盖，序列结束自动升起，亦可单独播放。
- **威力可视化** — 当量 1–1000 kt 滑块，按立方根定律 `R ∝ Y^(1/3)` 实时缩放火球 / 冲击波 / 热辐射 / 玻璃震碎等杀伤分区并标注公里数。

## 使用

直接双击 `index.html`，或本地起静态服务器：

```bash
python -m http.server 8000
# 浏览器打开 http://localhost:8000
```

鼠标拖动旋转 · 滚轮缩放 · 右键平移。

## 说明

仅用于科普与教育目的，几何尺寸、当量分区为示意性近似，不含任何武器制造信息。
