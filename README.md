# 核裂变与爆炸效应科学可视化 (Three.js)

> 当前版本：**v1.1**

博物馆式交互科学可视化：解释临界、裂变链式反应，以及能量释放后火球、热脉冲、冲击波和浮力云团在不同时间尺度上的演化。纯前端单文件，浏览器直接打开 `index.html` 即可（Three.js 通过 CDN 加载，需联网）。

## 功能

- **三段式叙事** — 裂变机制 / 时间演化 / 效应范围，开屏即可看见重点。
- **两种历史构型对照** — 保留内爆式与枪式概念剖面，但使用非工程比例和抽象部件说明。
- **链式反应可视化** — 实时显示裂变代数与相对裂变率，突出指数增长。
- **三种视图** — 整体 / 剖面（实时裁剪平面）/ 分解。
- **多时间尺度序列** — 微秒级链式反应、毫秒至秒级火球/冲击波、秒至分钟级云团演化分别计时。
- **大气效应** — 火球、热脉冲、三维冲击波、马赫环、短暂凝结云，以及粒子云柱和翻滚菌盖。
- **效应范围** — 当量滑块按不同经验指数缩放各类范围，并明确显示天气、地形、爆高等不确定性。
- **科学 HUD** — 典型能量分配、主导现象、当前时间尺度与教学提示实时更新。

## 使用

直接双击 `index.html`，或本地起静态服务器：

```bash
python -m http.server 8000
# 浏览器打开 http://localhost:8000
```

鼠标拖动旋转 · 滚轮缩放 · 右键平移。

## 说明

仅用于科普、课堂和博物馆式展示。结构是抽象概念模型，不含制造信息；空间比例与效应圆环均为示意性近似，不能用于现实预测或安全决策。
